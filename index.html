여행 타임라인파일이 업로드되지 않습니다

한국어 · English GitHub

Google Timeline 기록으로 집을 추정하고, 집에서 멀리 떠난 기간을 여행으로 묶어 보여줍니다. 모든 계산은 이 브라우저 안에서만 일어나며, 위치 기록 파일은 서버로 전송되지 않습니다.

타임라인 JSON 파일을 여기로 끌어다 놓으세요
또는 클릭해 파일을 선택하세요. 내보내기 메뉴는 기기마다 다릅니다. iPhone Google 지도 앱 → 프로필 → ⋯ → 위치 및 개인정보 설정 → 타임라인 데이터 내보내기 → 파일에 저장 (location-history.json) Android 휴대폰 설정 → 위치 → 타임라인 → 타임라인 데이터 내보내기 (Timeline.json)
기록 파일이 없어도 둘러볼 수 있습니다

파일을 넣으면 집을 기준으로 정리한 여행 목록과 지도, 자주 간 곳을 볼 수 있습니다.
